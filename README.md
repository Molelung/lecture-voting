# 朋辈社课投票网站（Lecture Voting System）

一套专为社团、研学小组与公开学术社课打造的**轻量级社课主题投票 Web 应用程序**。采用现代**液态玻璃（Liquid Glass）视觉风格**，界面简洁直白、零多余干扰，手机与电脑全端自适应，支持局域网直接扫码投票、一人一票防刷与实时数据看板。

---

## 快速上手与运行

### 1. 启动本地服务
打开终端进入项目根目录：
```bash
cd "D:\[长期项目] 【朋辈】社课\Coding\lecture-voting"
npm start
```
服务将在本地启动并监听 `http://localhost:3000`。

### 2. 局域网 / 手机扫码投票
在同一 Wi-Fi 或热点局域网下，只需让社员或同学在手机浏览器输入你的局域网 IP：
```text
http://<你的电脑局域网IP>:3000
```
即可直接打开投票，适配各类手机竖屏与微信内置浏览器。

## 核心功能特性

1. **液态玻璃（Liquid Glass）设计**：
   - 多层毛玻璃高斯模糊（Backdrop Blur）、柔和透光微倒角与流体光斑动效。
   - 底部浮动选票栏（Floating Dock），已选主题与剩余票数一目了然。
   - 简洁直白的卡片式排版，支持一键展开查看“社课大纲要点与预期收获”。

2. **身份登录与公平防刷**：
   - 支持学生输入学号/姓名快捷登记与自主注册，一人一票或一人多票由后台规则统一控制。
   - 密码加密存储，Token 安全验签，有效防刷票与重复提交。
   - 截止前若管理员开启“允许改票”，用户可随时返回调整自己的心愿社课。

3. **实时热度榜单（Results Dashboard）**：
   - 冠亚季军金银铜动态专属徽章，得票率与总票数可视化进度条。
   - 榜单权限支持自由切换（公开可见 / 投票后揭晓 / 仅管理员可见）。

4. **总控管理后台（Admin Console）**：
   - **默认管理员账号**：`admin`
   - **默认管理员密码**：首次部署时默认设置，登录后可在管理后台「全局配置与运维」中随时安全修改
   - **主题动态管理**：随时新增、编辑、删除社课主题（修改标题、主讲人、分类、标签、课程大纲等）。
   - **规则开关调节**：每人最大投票数（1~10 票）、投票状态切换（开放中 / 暂缓投票 / 截止锁定）。
   - **数据审计与导出**：查看所有投票人姓名与所投主题明细，支持一键导出 UTF-8 BOM CSV/Excel 表格。
   - **一键清空重置**：支持一键清空旧轮次选票，快速开启新一轮投票。

5. **纯本地离线运行（Zero Cloud Dependency）**：
   - Tailwind CSS 与 Vue 3 核心库已内置至 `/public/vendor`，无需依赖任何外网 CDN，内网/断网环境下秒级秒开。
   - 数据保存在 `/data/database.json`，单文件自动落盘持久化，备份迁移极其轻便。

## 线上部署与线路说明

### 访问地址
| 用途 | 地址 | 说明 |
| --- | --- | --- |
| 正式入口（推荐） | `https://vote.molan.cc.cd/` | 页面与接口同源，均由 Cloudflare 边缘就近直发 |
| 备用入口 | `https://vote.listener.ccwu.cc/` | 与正式入口互为备份，主线路异常时自动切换 |
| 老入口 | `https://molelung.github.io/lecture-voting/` | 打开后自动升级跳转到正式入口，并带上原有投票凭据 |

### 为什么页面不再直接从 GitHub Pages 打开
`public/` 目录虽然仍由 GitHub Pages 托管，但线上页面是由 **Cloudflare Worker（`lecture-voting-api`）反代 + 边缘缓存** 发出的：
- 同学们直连 `github.io` 在国内经常被限速甚至超时，改由 Cloudflare 边缘就近响应后首屏明显变快；
- 页面与 `/api` 变成**同源**，带 `X-Voter-Token` 的请求不再触发 CORS 预检，每次请求少一个往返；
- 源站（GitHub）临时不可用时，边缘继续发出上次缓存的副本；连缓存都没有时返回自动重连页，而不是白屏；
- 内容仍以本仓库为唯一来源，Worker 只做只读转发，不做任何改写，部署后约 1 分钟内全网生效。

### Worker 部署
改动 `server/cloudflare-worker.js` 后需要重新发布 Worker（`deploy_worker.mjs`，需含 Workers Scripts:Edit 权限的 Cloudflare API Token）。
Worker 绑定 `VOTING_KV`（KV）+ `DB`（D1），`vote.molan.cc.cd` 与 `vote.listener.ccwu.cc` 均以 Workers 自定义域名方式绑定。

### 弱网与网络波动处理
- **请求对冲**：主接入点超过 1.2 秒（写请求 2.5 秒）未响应，就并行发起备用接入点，谁先成功用谁，不必等满超时；
- **短超时**：单次请求 4 秒（写 6 秒）即中断并切线路，取代原来漫长的 10 秒；
- **接入点记忆**：上次可用的线路记在本地，刷新页面后不再从坏节点重新试错；
- **网络层失败一定抛出**：DNS 解析失败、连接被掐断等都会触发切换，不再静默变成"看似成功但没数据"；
- **离线暂存队列**：彻底断网时选票先存本地，恢复联网后自动补投，幂等接口保证不会重复计票。

### 二维码资产

站内「分享」弹窗的二维码按当前访问地址实时生成，会自动跟随所访问的域名。

烟花动画弹出，展示这个二维码并引导入群（仅首次投票弹出，改票不重复打扰）。

重新保存，裁到只剩二维码（保留白边），覆盖同名文件后 `git push`，约 1 分钟内全网上线。
文案在 `public/index.html` 的 `showGroupModal` 区块中修改。
