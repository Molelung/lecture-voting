# 朋辈社课投票网站（Lecture Voting System）

一套专为社团、研学小组与公开学术社课打造的**轻量级社课主题投票 Web 应用程序**。采用现代**液态玻璃（Liquid Glass）视觉风格**，界面简洁直白、零多余干扰，手机与电脑全端自适应，支持局域网直接扫码投票、一人一票防刷与实时数据看板。

---

## 快速上手与运行

### 1. 启动本地服务
打开终端进入项目根目录：
```bash
cd "D:\[长期项目] 【朋辈】社课\Coding\lecture-voting"
npm start
```
服务将在本地启动并监听 `http://localhost:3000`。

### 2. 局域网 / 手机扫码投票
在同一 Wi-Fi 或热点局域网下，只需让社员或同学在手机浏览器输入你的局域网 IP：
```text
http://<你的电脑局域网IP>:3000
```
即可直接打开投票，适配各类手机竖屏与微信内置浏览器。

## 核心功能特性

1. **液态玻璃（Liquid Glass）设计**：
   - 多层毛玻璃高斯模糊（Backdrop Blur）、柔和透光微倒角与流体光斑动效。
   - 底部浮动选票栏（Floating Dock），已选主题与剩余票数一目了然。
   - 简洁直白的卡片式排版，支持一键展开查看“社课大纲要点与预期收获”。

2. **身份登录与公平防刷**：
   - 支持学生输入学号/姓名快捷登记与自主注册，一人一票或一人多票由后台规则统一控制。
   - 密码加密存储，Token 安全验签，有效防刷票与重复提交。
   - 截止前若管理员开启“允许改票”，用户可随时返回调整自己的心愿社课。

3. **实时热度榜单（Results Dashboard）**：
   - 冠亚季军金银铜动态专属徽章，得票率与总票数可视化进度条。
   - 榜单权限支持自由切换（公开可见 / 投票后揭晓 / 仅管理员可见）。

4. **总控管理后台（Admin Console）**：
   - **默认管理员账号**：`admin`
   - **默认管理员密码**：`admin123`（进入后台后或在数据库可修改）
   - **主题动态管理**：随时新增、编辑、删除社课主题（修改标题、主讲人、分类、标签、课程大纲等）。
   - **规则开关调节**：每人最大投票数（1~10 票）、投票状态切换（开放中 / 暂缓投票 / 截止锁定）。
   - **数据审计与导出**：查看所有投票人姓名与所投主题明细，支持一键导出 UTF-8 BOM CSV/Excel 表格。
   - **一键清空重置**：支持一键清空旧轮次选票，快速开启新一轮投票。

5. **纯本地离线运行（Zero Cloud Dependency）**：
   - Tailwind CSS 与 Vue 3 核心库已内置至 `/public/vendor`，无需依赖任何外网 CDN，内网/断网环境下秒级秒开。
   - 数据保存在 `/data/database.json`，单文件自动落盘持久化，备份迁移极其轻便。
